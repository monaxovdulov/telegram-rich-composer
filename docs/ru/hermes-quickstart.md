# Hermes: установка заданием

[English version](../en/hermes-quickstart.md)

Hermes поддерживает Telegram Rich Messages. Это задание установит skill, который задаёт форму ответа: короткий вывод, следующий шаг, индекс и сворачиваемые подробности.

## Установка

Отправьте Hermes или агенту с доступом к компьютеру этот текст:

```text
Установи Telegram Rich Composer в активный профиль Hermes.

Источник:
https://github.com/monaxovdulov/telegram-rich-composer/tree/main/skills/telegram-rich-composer

Порядок работы:
1. Определи активный профиль Hermes.
2. Изучи skill и установи его штатной командой Hermes.
3. Убедись, что gateway.platforms.telegram.extra.rich_messages в config.yaml имеет значение true.
4. Для изменения config.yaml сначала создай резервную копию. После изменения проверь YAML и перезапусти gateway.
5. Сохрани остальные настройки и секреты.
6. Сообщи результат установки и готовность к тесту.

При ошибке остановись и укажи одно действие, которое требуется от меня.
```

## Проверка

Отправьте Hermes:

```text
Используй Telegram Rich Composer.

Перед запуском продукта известны три факта:
- конверсия выросла с 4,1% до 5,0%;
- число ошибок осталось прежним;
- удержание измерено за два дня.

Дай решение и следующий шаг в первых трёх строках. Затем добавь однострочный индекс. Размести основание, план проверки и риски в отдельных сворачиваемых разделах. Оставь предупреждения и обязательные действия открытыми.
```

Готовый ответ начинается с решения, следующего шага и индекса. Ниже находятся три сворачиваемых раздела.

Если разделы отображаются обычным текстом, попросите агента проверить флаг `gateway.platforms.telegram.extra.rich_messages` и перезапустить gateway.

[Полная инструкция по интеграции](adapters.md) описывает остальные варианты подключения.
