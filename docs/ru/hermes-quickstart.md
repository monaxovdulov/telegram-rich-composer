# Hermes: подключение без терминала

[English version](../en/hermes-quickstart.md)

Этот способ подходит, если Hermes уже отвечает вам в Telegram. Вы отправляете готовое задание агенту, а он проверяет установку, меняет настройку и готовит тест.

Для первого запуска используется лёгкая версия skill для Hermes. Она работает через штатный Telegram-адаптер. Python-пакет и сторонний plugin пока не нужны.

## Что изменится в ответах

Короткие реплики останутся обычным текстом. В длинном ответе Hermes сможет оставить вывод и следующий шаг сверху, добавить короткий индекс, а доказательства, сравнение и риски убрать в сворачиваемые разделы.

Предупреждения и обязательные действия всегда остаются видимыми.

## Задание для агента

Отправьте текст ниже Hermes или другому coding agent, у которого есть доступ к компьютеру с Hermes.

```text
Подключи к моему активному профилю Hermes skill Telegram Rich Composer.

Источник:
https://github.com/monaxovdulov/telegram-rich-composer

Цель:
В Telegram короткие ответы должны остаться обычными. Для длинного ответа сначала показывай вывод и следующий шаг, затем однострочный нумерованный индекс. Доказательства, сравнение и риски помещай в отдельные сворачиваемые <details>.

Сначала проверь окружение:
1. Определи активный профиль Hermes и его HERMES_HOME. Не считай, что это всегда ~/.hermes.
2. Проверь версию Hermes и наличие команд `hermes skills inspect` и `hermes skills install`.
3. Изучи skill до установки:
   hermes skills inspect monaxovdulov/telegram-rich-composer/skills/telegram-rich-composer
4. Если команда отсутствует или проверка безопасности блокирует установку, остановись и объясни причину. Не используй --force без моего разрешения.

Затем установи и проверь skill:
1. Выполни:
   hermes skills install monaxovdulov/telegram-rich-composer/skills/telegram-rich-composer --yes
2. Убедись через `hermes skills list`, что установлен telegram-rich-composer.
3. Не подключай сторонний plugin и не устанавливай Python-пакет для первого теста. Используй штатный Telegram Rich Message transport Hermes.

Аккуратно включи Rich Messages:
1. Найди config.yaml активного профиля и сделай резервную копию рядом с ним.
2. Сохрани все существующие настройки и добавь или обнови только эти поля:

   gateway:
     platforms:
       telegram:
         extra:
           rich_messages: true
           rich_drafts: false

3. Не показывай и не меняй токен Telegram, списки разрешённых пользователей, chat ID, topic ID и другие секреты.
4. Проверь итоговый YAML. Если перезапуск gateway безопасен и сессия сможет продолжиться, выполни `hermes gateway restart`. Иначе остановись и скажи, какое одно действие осталось сделать мне.

После установки сообщи:
- какой профиль и config.yaml использованы;
- куда установлен skill;
- какие два поля конфигурации изменены;
- перезапущен ли gateway;
- как откатить изменения.
```

Hermes проверит skill как сторонний источник. Задание разрешает автоматическую установку только после того, как агент подтвердил репозиторий `monaxovdulov/telegram-rich-composer`. При другом источнике он должен остановиться.

## Первый тест в Telegram

После перезапуска отправьте Hermes это сообщение:

```text
Используй Telegram Rich Composer.

Представь, что перед запуском продукта у нас есть три факта:
- конверсия выросла с 4,1% до 5,0%;
- число ошибок не изменилось;
- удержание измерено только за два дня.

Сначала дай решение и следующий шаг максимум в трёх строках. Затем добавь однострочный индекс. Основание, план проверки и риски помести в три отдельных сворачиваемых раздела. Не прячь предупреждение или обязательное действие.
```

В начале сообщения должны остаться решение, следующий шаг и индекс. Ниже появятся три раздела, которые можно раскрывать по одному.

## Если разделы не сворачиваются

Попросите агента проверить четыре вещи:

1. Hermes обновлён и поддерживает Telegram Rich Messages.
2. Настройка находится по точному пути `gateway.platforms.telegram.extra.rich_messages`.
3. Gateway перезапущен после изменения `config.yaml`.
4. Telegram-клиент обновлён.

Hermes оставляет Rich Messages выключенными по умолчанию из-за различий между клиентами. Для первого теста `rich_drafts` лучше оставить выключенным. Если Telegram отклонит Rich Message, Hermes должен отправить читаемый запасной вариант без повторной отправки после неизвестного сетевого результата.

Актуальные ограничения описаны в [официальной инструкции Hermes для Telegram](https://hermes-agent.nousresearch.com/docs/user-guide/messaging/telegram/).

## Откат

Попросите агента удалить `telegram-rich-composer`, вернуть `rich_messages: false` и перезапустить gateway. Резервная копия `config.yaml` нужна только для восстановления, если агент случайно изменил соседние настройки.

Для проверки через `CompositionSpec`, Python API или plugin перейдите к [полной инструкции по адаптерам](adapters.md).
