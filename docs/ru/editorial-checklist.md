# Редакционный checklist

[English version](../en/editorial-checklist.md)

- Первый видимый блок отвечает пользователю?
- Для этого сообщения plain text не будет яснее?
- Каждый заголовок обозначает реальный раздел?
- Предупреждения, влияние и обязательные действия видны без раскрытия details или spoiler?
- У каждого акцента одна задача?
- Collage применяется для одновременного сравнения, а slideshow для последовательности?
- Ячейки таблицы достаточно короткие для телефона?
- Подписи объясняют медиа, а credit указывает происхождение?
- В details находится вторичный материал, а обычная вложенность не превышает одного-двух уровней?
- Кнопки представляют реальный выбор или действие?
- Fallback сохраняет вывод, предупреждения, порядок, подписи и ссылки?
- Адаптер сохранил доверенный reply и topic context?
