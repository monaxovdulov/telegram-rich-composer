# Editorial checklist

[Русская версия](../ru/editorial-checklist.md)

- Does the first visible block answer the user?
- Would plain text be clearer for this turn?
- Does each heading name a real section?
- Are warnings, impact, and required actions visible rather than collapsed or spoiled?
- Does every accent have one job?
- Is a collage used for simultaneous comparison and a slideshow for sequence?
- Are table cells short enough for a phone?
- Do captions explain media and credits identify provenance?
- Are details secondary, with no more than one or two nesting levels in normal use?
- Do buttons represent a real choice or action?
- Does fallback preserve the conclusion, warnings, order, captions, and links?
- Has the adapter preserved the trusted reply and topic context?
